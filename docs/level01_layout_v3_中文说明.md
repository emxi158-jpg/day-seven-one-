# 《第七日》第一关自动摆放 v3 · 中文使用说明

## 脚本地址
[blender/level01_auto_layout.py](../blender/level01_auto_layout.py)

## 生成内容
- 主工作室：9m × 11m × 3.4m，保留入口、后窗和中央通行区域。
- 右墙外附加的隐藏房间：3.35m × 3.3m × 2.85m；主墙已留 1.25m 门洞。
- **完整电脑桌组合**使用 `Complete Office Workplace Setup` 原集合实例：不拆分、不缩放、不旋转，仅整体平移。
- 原有沙发、抽屉柜按整体等比缩放，分别放在右前和右后。
- 从另一份 Blender 文件中追加 `Antique Bookcase` 集合，放在左墙。
- 书柜外明显散落的、可明确识别的独立书籍只在新布局的来源副本中**隐藏**，不破坏原始模型；其他书籍不会胡乱删除。
- 隐藏房间内独立设置木桌、木椅、CRT 的可替换占位模型，并显示 PLAYER / ZERO / SAVE / LOAD / RESET 文字。
- 右墙隐藏门目前只是**墙皮预览占位**（对象名含 `NO_COLLISION`），实际透视影门谜题、Godot 碰撞/交互须在后续阶段制作。

## 如何使用（Blender 中文版）
1. 打开包含完整电脑桌组合的原始 `studio_original.blend`。
2. 用「文件 → 另存为」备份原始工程。
3. 把书柜源文件 `studio_original(1).blend` 放在同一文件夹中，**或**打开脚本，把顶部 `BOOKCASE_BLEND_PATH = ""` 改为书柜文件的 Windows 绝对路径，如 `r"D:\Models\bookcase.blend"`。
4. 在 GitHub 打开脚本文件，点「下载原始文件」。
5. 回 Blender「脚本」工作区，点击文本编辑器的「打开」，选择下载的 `.py` 文件。
6. 点「运行脚本」（或在文本编辑器中按 Alt + P）。
7. 通过 Blender 顶部场景下拉菜单切换到新建的 `LEVEL01_Workshop_With_SaveRoom` 场景；检查家具尺寸和书柜位置。
8. **文件 → 另存为** `level01_workshop_v3.blend`，不要覆盖原版。
9. 由于模型有 BlenderKit 资源，请不要将包含不允许再分发的原始模型的 .blend 文件直接上传到公开仓库。

## 有问题时
- 书柜未出现：打开「窗口 → 切换系统控制台」查看日志，检查源文件路径以及内部书柜集合名；默认优先 `Antique Bookcase`，其次 `Bookshelf`。
- 办公桌不见了：确认原工作文件有名为 `Complete Office Workplace Setup` 的集合。
- 桌子超大/很小：脚本刻意保持原始尺寸。需要检查原模型实际导入单位，而不是缩放已搭好的桌子。
- 场景重复生成：每次运行会产生新场景（Blender 自动加 `.001` 后缀），不会覆盖旧场景。
- 书柜里有多余书籍仍保留：自动清理是保守策略，不会猜测并删除柜内书；后续可以根据截图再细调过滤规则。

**注意：本脚本已做代码层面的检查，但尚未在你的 Blender 版本内实际运行。**
